# fund.mithril.siso.msdl

Versioned MSDL native XML profile plugin: `SISO-STD-007-2008`.
Operations: msdl-import, msdl-project. Bundled explicit XPath mapping; native source bytes remain preserved.

`python -m pip install -e .` installs the pinned XML/host dependencies and registers the plugin.

The structural fixture is not certified against a complete official MSDL XSD.

Projection does not execute military commands or initialize a simulator.
